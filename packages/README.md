# @echolotl/\* packages

This folder contains packages used between **multiple services** in the repo. I'll document what does what so maybe they could be used elsewhere? I try to keep everything here as disconnected from the app as possible, so they could be used standalone maybe, but not always the case. Especially with things that are specifically made to **only share data between the services**.

| Package              | Description                                                                                                                                                                                                                                                                                                                                                 |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@echolotl/logger`   | Shared stylized logger and ANSI formatting helpers used by the frontend and backend                                                                                                                                                                                                                                                                         |
| `@echolotl/types`    | Shared types for use between the frontend and backend (possibly more services in the future)                                                                                                                                                                                                                                                                |
| `@echolotl/picross`  | The picross engine used for [echolotl.lol/picross](https://echolotl.lol/picross). This includes the solver, seeded puzzle generator, the `.epcp` file format, and functions for all of it exported. Daily dates are hardcoded, but it's all self-contained, so maybe it could be used elsewhere. I'd like to rewrite the solver into a WASM module one day. |
| `@echolotl/flashish` | A path-to-fill drawing canvas state handler. It's supposed to work similarly to Adobe Flash/Animate/Illustrator's drawing, where drawn strokes are converted into filled paths. It uses Paper.js under the hood. Generally self-contained, but uses owner/actor ids for it's purpose on [echolotl.lol/guestbook](https://echolotl.lol/guestbook)'s canvas.  |
